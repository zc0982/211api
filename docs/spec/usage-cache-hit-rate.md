# 使用记录的缓存命中率

用户端和管理端按输入 Token 数量计算缓存命中率。分子是缓存读取 Token，分母是未缓存输入、缓存读取、缓存写入三项 Token 之和。输出 Token 不参与计算，缓存写入的各个 TTL 明细已经包含在写入总数中。

- 每条记录使用本次请求的 Token 数量。顶部「总 Token」卡片使用当前筛选范围内各项 Token 的合计值计算，覆盖全部分页。
- 有输入但没有缓存读取时显示 `0.0%`。分母为零时，汇总和明细显示 `—`，导出单元格留空。
- 用户 CSV 使用一位小数的百分比文本，管理员 Excel 使用可计算的百分比数值。两种导出都在原有列之后追加缓存命中率。
