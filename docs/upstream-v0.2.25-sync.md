## 升级行为

- API Key 账号的请求头覆写可引用经认证的网关身份。WebSocket 连接按实际上报的身份隔离复用，握手省略请求级的 `request_id`。运维错误详情可看到该次转发所上报的身份头。
- 管理员可根据上游分组同步账号名称和备注。自动同步默认关闭，启用后复用现有倍率探测请求。只有通过校验的非空字段会覆盖本地值。`/v1/sub2api/billing?include=group` 可返回调用密钥绑定的分组名称和描述。
- OpenAI 透传支持现有错误透传规则，保留特定 400 错误的结构化字段，并对客户端可见字段脱敏。Compact 流中的部分上游过载错误改写为可重试错误。
- 上游错误消息先移除 HTTP(S) URL 中的用户名和密码，再屏蔽敏感查询参数。这覆盖 OpenAI 透传的结构化 JSON 错误，以及 Compact 心跳已发送时由网关生成的 `response.failed` 事件。
- 升级 `github.com/gorilla/websocket` 至 `v1.5.4-0.20240701034025-d67f41855da4`。
- 本次没有新增数据库迁移。分组自动同步开关保存在既有的 `accounts.extra` 中。
